# 10. Stabilization — обзор

## Статус

Рабочие maintenance-документы, не архитектурные контракты. Источник — два
полных аудита репозитория в состоянии `main` после коммита `39bbdd0`
("fix: localize port block validation errors"): полный code review и
performance/scalability review перед стартом L2.

Эти документы фиксируют находки и план стабилизации так, чтобы последующие
implementation-сессии не зависели от истории бесед. Они **самодостаточны**:
для постановки и реализации milestone достаточно 10.1–10.3 и актуального кода
и docs `main`; полные тексты старых аудитов не являются обязательным источником
и нигде не требуются. Документы НЕ вводят новых архитектурных решений: всё,
что требует product/architecture выбора, помечено как отдельный пункт, а не
реализовано молча.

## Состав

- [[10-01-audit-findings|10.1 Реестр находок аудитов]] — компактные результаты

- [[10-02-stabilization-backlog|10.2 Stabilization backlog]] — единый список

- [[10-03-performance-baseline|10.3 Performance baseline и бюджеты]] — профили
  данных, метрики, целевые значения и способ их получения.

## Правила работы с backlog

1. Единственный канонический список задач — 10.2. Находки в 10.1 существуют
   только как обоснование пунктов; при расхождении приоритет у 10.2.
2. Статусы: `TODO` → `IN PROGRESS` → `DONE` (+ дата/коммит) или `WONTFIX`
   (с причиной). Не удалять пункты.
3. Severity отражает риск для продукта сейчас, а не объём работы.
4. Пункты с «benchmark: обязателен» нельзя выполнять до завершения PERF-001
   (benchmark foundation) и фиксации baseline из 10.3.
5. Дубли между аудитами устранены: у каждой работы один канонический пункт в
   10.2; пересекающиеся находки сведены в него без отдельных ярлыков.

## Границы применимости

- L2/L3/NAT/packet-processing резолверы в полном code review проверялись на
  уровне границ и инвариантов (read-only дисциплина, UNKNOWN-semantics через
  тесты), а не построчно. Прицельный predicate-level pass по docs/01-04…01-07
  остаётся отдельной будущей задачей и в backlog сознательно не включён без
  конкретных находок.
