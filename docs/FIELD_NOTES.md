# Актуальные замечания эксплуатации NetMap

Этот журнал содержит только **незавершённые** замечания пользователя.
Выполненные записи удаляются после приёмки и слияния соответствующей задачи;
история доступна в Git и документации milestones. Основной план —
[BACKLOG](BACKLOG.md), правила ведения — [контракт координатора](chatgpt.md#замечания-из-практической-эксплуатации).

Идентификаторы `FN-NNN` уникальны и никогда не выдаются повторно.
Последний выданный номер: **FN-022**. Следующий новый номер — **FN-023**.

## Статусы

- `OPEN` — требуется согласование решения.
- `PLANNED` — решение согласовано, выполнение ещё не принято и не объединено.
- `DEFERRED` — отложено, указаны причина или зависимость.
